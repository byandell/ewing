hexmoveApp (Organism Movement on Hex Grid)

Interactive Shiny app to visualize organism positions on a continuous hexagonal substrate grid based on global tridiagonal coordinates and step through simulation events.
Author

Brian S. Yandell

← Back to Demos Gallery

The hexmoveApp() application visualizes host and parasite spatial positions mapped directly onto a unified hexagonal substrate network topology (create_substrate).

Instead of rendering substrate components (fr1..fr4, tw1..tw2, lftop, lfbot) in isolated rectangular panel facets, hexmoveApp() places every organism on a continuous hexagonal substrate plane based on its native tridiagonal coordinates \((a, b, c)\) rescaled into its active substrate patch area.

Interactive Application Usage

Launch the application natively in R:

library(ewing)

# Initialize simulation and run initial 100 steps
mysim <- init.simulation()
mysim <- future.events(mysim, nstep = 100)

# Launch interactive Shiny app
hexmoveApp(mysim)

[!NOTE] Live Deployment: You can also test hexmoveApp() live on the SystemsEthology Connect Platform.

Key Features

  1. Per-Substrate Unit Triangle Rescaling: Organisms’ local tridiagonal coordinates \((pos.a, pos.b, pos.c)\) are normalized and scaled into the unit triangle \([0, W_{sub}]\) of each active substrate patch, guaranteeing all individuals sit strictly within their substrate bounds (and supporting substrates of varying sizes).
  2. Hexagonal Polygon Overlay: Generates discrete 6-sided polygon cells (create_hex_overlay) across all plant substrate components (fr1..fr4, tw1, lftop, lfbot).
  3. Interactive Simulation Stepping: Action buttons (Step +1, Step +10, Step +100, Reset) allow stepping through simulation horizon events with live reactive map updates.
  4. Modular Layout Composition: Seamlessly switch between "hex" (global hexagonal grid overlay) and "facet" (panel view faceted by substrate element) layouts in substrateInput / substrateServer.
